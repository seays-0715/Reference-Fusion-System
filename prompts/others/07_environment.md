# Goal

Edit the Base Image by transferring ONLY the environment from the Reference Image.

---

# Image Roles

## Base Image

Image 1

The image to edit.

Preserve this image as the foundation of the final result.

---

## Reference Image

Image 2

Use ONLY as the reference for the environment.

Do not copy unrelated visual information from this image.

---

# Primary Instruction

Transfer ONLY:

- Environment

Replicate the environment from the Reference Image as accurately as possible.

This includes:

- Location
- Scene
- Architecture
- Interior or exterior setting
- Terrain
- Ground surface
- Walls
- Floor
- Ceiling
- Windows
- Doors
- Furniture
- Fixtures
- Decorative objects
- Stationary scene objects
- Vegetation
- Natural landscape
- Weather-related scene elements
- Spatial layout

Match the reference faithfully.

Do not reinterpret, redesign, stylize, or approximate the reference unless explicitly requested.

---

# Secondary Instruction

Preserve all unrelated visual attributes from the Base Image.

---

# Stage-specific Restrictions

- Do not transfer facial identity, hairstyle, facial expression, body characteristics, wearable wardrobe, props, pose, camera composition, lighting, or rendering style from the Reference Image.
- Preserve the established character identity, canonical body, wearable wardrobe, props, pose, camera composition, lighting, and rendering style from the Base Image.
- Transfer only the surrounding environment.
- Preserve the established interaction between the character and existing props.
- Generate only the minimum necessary environmental adjustments required to naturally integrate the preserved character into the transferred environment.
- Generate any necessary supporting surfaces or surrounding structures required by the established pose and props, such as floors, walls, chairs, beds, tables, railings, or similar environmental elements.
- Maintain realistic scale, perspective, spatial consistency, physical contact, and environmental coherence.
- Do not introduce additional characters unless they are explicitly intended to be part of the environment.

---

# Output Constraint

The output should appear identical to the Base Image, with only the environment transferred from the Reference Image.

Apply only the minimum necessary modifications required to complete the requested edit.

Generate a natural, visually coherent, and physically consistent result.
