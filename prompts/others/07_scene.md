# Goal

Character asset design sheet for a story-driven graphic novel.

Edit the Base Image by changing ONLY the scene.

---

# Image Roles

## Base Image

Image 1

The image to edit.

Preserve this image as the foundation of the final result.

---

## Reference Image

Image 2

Scene reference only.

Use this image ONLY to determine the scene.

Ignore all unrelated visual information.

---

# Primary Instruction

Transfer ONLY the scene from the Reference Image.

Replicate the scene as accurately as possible.

This includes:

- Location
- Architecture
- Spatial layout
- Ground
- Floor
- Walls
- Ceiling
- Windows
- Doors
- Furniture
- Permanent scene objects
- Vegetation
- Static decorations

Do not reinterpret, redesign, or approximate the scene unless explicitly requested.

---

# Secondary Instruction

Everything unrelated to the scene must remain exactly as it appears in the Base Image.

Preserve:

- Identity
- Face
- Hairstyle
- Body
- Wardrobe
- Props
- Pose
- Camera composition
- Subject framing

---

# Stage Responsibility

Modify ONLY the scene.

Do not intentionally modify any other visual attributes.

Apply only the minimum necessary adjustments required to achieve natural scene consistency.

---

# Stage-specific Restrictions

Do not transfer from the Reference Image:

- Character identity
- Face
- Hairstyle
- Body
- Clothing
- Accessories
- Props
- Pose
- Expression

Do not add, remove, or replace characters unless explicitly requested.

---

# Output Constraint

The output should appear identical to the Base Image, with only the scene changed.
