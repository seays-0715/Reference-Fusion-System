# Goal

Stage:
Identity Master (Multi)

Objective:
Create and lock a new canonical character identity by naturally synthesizing multiple human reference identities into a single unique person. This image becomes the master reference for all future generations.

---

# Reference Assignment

Image 1:
Primary Human Identity Reference.

Image 2+:
Supporting Human Identity References.

All reference images contribute to the final identity.

No single reference should dominate unless explicitly specified.

*Note: Reference images define ONLY the character identity. Clothing, pose, expression, camera, lighting, and background are overridden by this prompt.*

---

# Priority

Highest Priority:
Create one believable, naturally occurring identity.

Priority Order:

1. Natural Blended Identity
2. Facial Identity & Structure
3. Body Proportions & Physique
4. Hairstyle & Skin Tone
5. Standardized Capture Setup

---

# Identity Synthesis

Generate a completely new person inspired by all provided reference identities.

The final identity must:

- look like one naturally born individual
- preserve recognizable characteristics from all references
- avoid appearing as a face swap
- avoid appearing as an image overlay
- avoid obviously resembling only one reference

Naturally synthesize:

- facial identity
- facial structure
- hairstyle
- hair color
- skin tone
- apparent age
- body build
- body proportions

When multiple references differ, create the most harmonious and biologically plausible combination rather than mechanically averaging individual features.

# Restrictions

Do NOT:

- copy one reference entirely
- create a face swap
- overlay multiple identities
- create an unrealistic facial structure
- create unrealistic body proportions
- crop or hide any body part
- add accessories
- add background objects
- add decorative elements
- apply stylized artistic effects

---

# Output

Generate a clean, photorealistic standardized character reference.

Requirements:

- unique synthesized identity
- natural facial structure
- realistic body proportions
- high identity consistency
- neutral presentation
- studio-quality photography
