# Goal

Character asset design sheet for a story-driven graphic novel.

Edit the Base Image by transferring ONLY the specified visual attribute from the Reference Image.

---

# Image Roles

## Base Image

Image 1

The image to edit.

Preserve this image as the foundation of the final result.

---

## Reference Image

Image 2

Use ONLY as the reference for the character's props.

Do not copy unrelated visual information from this image.

---

# Primary Instruction

Transfer ONLY:

- Character Props

Replicate the character's props from the Reference Image as accurately as possible.

This includes objects that are:

- Held
- Carried
- Equipped
- Attached externally
- Accompanying the character

Examples include:

- Handbags
- Backpacks
- Briefcases
- Suitcases
- Umbrellas
- Books
- Phones
- Tablets
- Laptops
- Cameras
- Musical instruments
- Sports equipment
- Medical equipment
- Tools
- Weapons
- Shields
- Plush toys
- Companion objects
- Other non-wearable character-related objects

Match the reference faithfully.

Do not reinterpret, redesign, stylize, or approximate the reference unless explicitly requested.

---

# Secondary Instruction

Preserve all unrelated visual attributes from the Base Image.

---

# Stage-specific Restrictions

- Do not transfer facial identity, hairstyle, facial expression, body characteristics, wearable wardrobe, pose, environment, camera, lighting, or rendering style from the Reference Image.
- Preserve the established character identity, canonical body, wearable wardrobe, pose, environment, camera, lighting, and rendering style from the Base Image.
- Adapt the transferred props naturally to the existing character and pose.
- Minor adjustments to finger articulation, hand placement, wrist orientation, clothing deformation, straps, or attachment points are permitted only when necessary for realistic interaction with the transferred props.
- Do not introduce additional props that are not present in the Reference Image.
- Maintain realistic object scale, weight, attachment, contact, and physical interaction.

---

# Output Constraint

The output should appear identical to the Base Image, with only the character's props transferred from the Reference Image.

Apply only the minimum necessary modifications required to complete the requested edit.

Generate a natural, visually coherent, and anatomically consistent result.
