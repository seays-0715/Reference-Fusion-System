# Goal

Character asset design sheet for a story-driven graphic novel.

Edit the Base Image by transferring ONLY the specified visual attribute from the Reference Image.

---

# Image Roles

## Base Image

Image 1

The image to edit.

Preserve this image as the foundation of the final result.

---

## Reference Image

Image 2

Use ONLY as the reference for the character's expressive gestures.

Do not copy unrelated visual information from this image.

---

# Primary Instruction

Transfer ONLY:

- Expressive Gestures

Replicate the expressive gestures from the Reference Image as accurately as possible.

This includes:

- Hand gestures
- Finger articulation
- Wrist articulation
- Arm gestures
- Hand placement
- Hand-to-hand interaction
- Hand-to-body interaction
- Expressive upper-body gestures

Match the reference faithfully.

Do not reinterpret, redesign, stylize, or approximate the reference unless explicitly requested.

---

# Secondary Instruction

Preserve all unrelated visual attributes from the Base Image.

---

# Stage-specific Restrictions

- Do not transfer facial identity, hairstyle, facial expression, body characteristics, overall body pose, wearable wardrobe, props, environment, camera, lighting, or rendering style from the Reference Image.
- Preserve the established character identity, canonical body, overall body pose, wearable wardrobe, props, environment, camera, lighting, and rendering style from the Base Image.
- Preserve the established overall body pose, including head orientation, torso orientation, pelvis orientation, leg position, foot placement, body balance, and stance.
- Preserve all established handheld and equipped props, generating only the minimum necessary hand, finger, and wrist articulation required to support them naturally.
- Generate only the minimum necessary arm, wrist, hand, and finger movement required to reproduce the transferred expressive gesture without altering the established overall pose.
- Minor adjustments to clothing, accessories, props, hair, or object attachment are permitted only when required to maintain realistic physical interaction with the transferred gesture.
- Maintain anatomical consistency, natural expressiveness, and believable physical interaction.

---

# Output Constraint

The output should appear identical to the Base Image, with only the character's expressive gestures transferred from the Reference Image.

Apply only the minimum necessary modifications required to complete the requested edit.

Generate a natural, visually coherent, and anatomically consistent result.
